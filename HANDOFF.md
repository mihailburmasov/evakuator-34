# Передача проекта: эвакуатор-34.рф

Состояние на 26.10.2026. Для того, кто продолжит работу над сайтом.

## Ссылки

- Репозиторий: https://github.com/mihailburmasov/evakuator-34
- Превью: https://mihailburmasov.github.io/evakuator-34/ — закрыто от индексации, Метрики нет, собирается автоматически при пуше в `main`.
- Боевой сайт: https://эвакуатор-34.рф — **пока старый**, на конструкторе REG.RU. Новый туда не выкладывался.

## Что сделано

- Новый сайт, 17 страниц и 404:
  - главная — Волжский;
  - 6 страниц услуг;
  - 7 страниц районов (Знаменск — Астраханская область);
  - цены, контакты, политика конфиденциальности.
- Статический сайт без CMS: Python-генератор `build.py`, факты в `data/site.json`, тексты в `content.py`. Подробности — в [README.md](README.md).
- Перенесено со старого сайта: прайс, фото, тексты, код Вебмастера, **оба** счётчика Метрики. Главная остаётся на `/`.
- Проверено:
  - нет горизонтальной прокрутки на ширинах 320–1920 px, на всех страницах;
  - нет ошибок консоли;
  - доступность (axe) — чисто на главной, контактах и странице Знаменска; на остальных страницах axe не перезапускался после правок;
  - уникальные title и description, один H1 на страницу, JSON-LD.

## Принятые решения — не пересматривать без причины

- **Главная — та же страница**, а не новая посадочная. Так сохраняется накопленный вес.
- **Оба счётчика Метрики остаются**, пока не выяснено, к какому привязан Директ.
- **Время подачи на сайте не указано.** Клиент его не называл, а выдумывать нельзя.
- **5 пассажирских мест — только у ГАЗели.** У Hyundai на 5 т кабина обычная, поэтому на сайте написано «есть эвакуатор с кабиной на 5 мест».
- **Отзывов нет**, пока нет настоящих.
- **Калькулятора нет.** Все цены «от», поэтому любая сумма в калькуляторе была бы выдуманной.
- Шрифты Oswald и PT Sans: ИИ-шные шрифты по правилам студии запрещены.
- Тема светлая и тёплая. Пользователь забраковал чёрный и графитово-синий фон, не возвращать их.
- Первый экран главной: фото на всю ширину, слева градиент в кремовый — по образцу plitka-volzhsky.
  - Фото стоковое (CC0, отзеркалено, номера размыты), подписано «Фото для примера».
  - У клиента фото только 1178 px, для фона на весь экран это мало. Если клиент пришлёт широкое фото своего эвакуатора, поставить его.
  - unsplash.com и Pexels из РФ не открываются, поэтому фото с Wikimedia Commons.

## Что осталось

**От клиента** (полный список выводит `python build.py`):

1. WhatsApp / Telegram / MAX.
2. Юрлицо или ИП, ИНН, ОГРН, e-mail, адрес — для политики конфиденциальности по 152-ФЗ.
3. Куда слать заявки с формы. Пока форма честно отвечает «демо-версия, звоните».
4. Время подачи эвакуатора.
5. Подтвердить «15 738 клиентов» и год начала работы.
6. Где базируется эвакуатор в каждом районе — чтобы районные страницы стали содержательнее.
7. Вычитать тексты: все страницы услуг и районов помечены `draft`.

**Хостинг не выбран.** REG.RU-конструктор статику не примет. `.htaccess` написан под Apache. Переносить домен — только с согласия владельца.

**Запуск:**

1. Заполнить todo и снять draft. После этого `python build.py --prod` соберёт сайт; пока они есть, сборка останавливается и `dist/` не трогает.
2. Залить `dist/` на хостинг.
3. Проверить редиректы через `curl -I` (команды в README; там же — что делать при петле HTTPS-редиректа).
4. В Вебмастере: переобход `/` и загрузка `sitemap.xml`.
5. В Метрике: цели `call`, `messenger`, `lead`.

## Подводные камни

- В Git Bash на Windows флаг `--base /evakuator-34` превращается в путь Windows. Локально запускать так: `MSYS_NO_PATHCONV=1 python build.py --staging --base /evakuator-34`. В GitHub Actions проблемы нет.
- Локальный `python -m http.server` в `dist/` держит папку открытой, поэтому сборщик чистит содержимое `dist/`, а не саму папку.
- `tools/prep_images.py` использует шрифты из `C:/Windows/Fonts` (для OG-картинки). Запускать его на Windows или поменять путь к шрифту.
