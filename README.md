# эвакуатор-34.рф — новый сайт

Статический сайт: 17 страниц и 404. Собирается Python-скриптом из одного файла фактов. Без CMS, jQuery и Bootstrap.

## Структура

| Путь | Что там |
|---|---|
| `data/site.json` | **Единственный источник фактов**: телефон, цены, счётчики Метрики, реквизиты. Неизвестное отмечено `{"todo": ...}` |
| `content.py` | Тексты страниц услуг и районов, FAQ |
| `build.py` | Генератор → `dist/` |
| `src/css`, `src/js`, `src/fonts`, `src/img` | Стили, скрипт, шрифты Oswald и PT Sans (свои файлы, не Google), фото в WebP |
| `tools/prep_images.py` | Пересобирает WebP, OG-картинку и иконки из фото старого сайта |
| `_old_site/` | Копия старого сайта: HTML и 4 фото |
| `src/vendor/leaflet/` | Leaflet 1.9.4 для карты на главной (тайлы OpenStreetMap). Подключается из `main.js`, только когда блок с картой доходит до экрана |
| `_stock/` | Стоковые фото. Плитки «Что случилось?» и карточки услуг: исходники `sit-*.jpg`, авторы и лицензии — `credits.json` (подписи выводит `build.py`, функция `credits_line`). Для внутренних страниц и картинки для соцсетей — [Logan на эвакуаторе, Cjp24, CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Dacia_Logan_sur_d%C3%A9panneuse.jpg); подпись с автором обязательна, `build.py` ставит её сам (`STOCK_CREDITS`). Для фона главной: [Wikimedia Commons, CC0](https://commons.wikimedia.org/wiki/File:Moscow,_yellow_Porsche_on_a_red-white_Iveco,_May_2026_01.jpg). `prep_images.py` размывает на нём номера и надписи и отзеркаливает его. На сайте подписано «Фото для примера». Когда будет широкое (от 2400 px) фото эвакуатора клиента, заменить его. |

```
python build.py          # черновик: пробелы в фактах видны оранжевыми пометками
python build.py --prod   # продакшен: не соберётся, пока есть todo/draft (выведет список)
cd dist && python -m http.server 8734   # посмотреть локально
```

## Как сохраняется накопленный вес

Старый сайт — одна страница на конструкторе REG.RU с пустыми title и description.

1. Главная остаётся на `/`. Весь старый контент перенесён на неё и расширен: прайс, «до 5 тонн / 5 мест», тексты, фото.
2. Перенесены без изменений:
   - `yandex-verification e61236fe8838e638`;
   - **оба** счётчика Метрики, 86876490 и 88134247. Удалять один из них можно только после того, как станет ясно, к какому привязан Директ.
3. Старые фото доступны по прежним адресам `/gallery_gen/*.jpg`: они могут быть в Яндекс Картинках.
4. В `.htaccess` (Apache) настроены 301-редиректы:
   - `http`→`https`;
   - `www`→без `www`;
   - `/index.php`→`/`: сейчас эта страница — дубль главной с кодом 200.
5. На всех страницах стоит canonical. Новые страницы только добавляются, старые адреса не пропадают.

После переноса:

- в Вебмастере: «Переобход страниц» для `/`, загрузить `sitemap.xml`;
- в Метрике: создать JS-цели `call`, `messenger`, `lead`. Сайт уже отправляет их в оба счётчика.

## Перед запуском — нужно от клиента

1. WhatsApp: тот же номер? Telegram и MAX — если есть.
2. Юрлицо или ИП, ИНН, ОГРН, e-mail, адрес — для политики конфиденциальности (152-ФЗ) и подвала.
3. Куда отправлять заявки с формы «Перезвоните мне»: Telegram-бот или почта. Пока форма честно пишет «демо-версия, звоните».
4. Подтвердить цифру «15 738 клиентов» (со старого сайта) и год начала работы («© 2005»).
5. Вычитать тексты страниц услуг и районов. Они собраны из старого сайта и открытых источников и помечены `draft`.
6. Время подачи эвакуатора. На сайте его сейчас **нет**, хотя это главный аргумент в рекламе. Конкуренты пишут разные цифры даже в пределах одного сайта. Нужна одна честная цифра для всего сайта.
7. Отзывы — только настоящие, лучше ссылкой на карточку в Яндекс Картах или 2ГИС.
8. По каждому району: где базируется закреплённый эвакуатор и куда чаще всего везут оттуда. Это развёрнутое «за каждым районом закреплены 1–2 эвакуатора». Даст каждой районной странице уникальный и правдивый текст — без этого они пока тонковаты для SEO.

## Хостинг

Сейчас сайт на конструкторе REG.RU, статический сайт туда не загрузить. Нужен обычный хостинг (`.htaccess` написан под Apache) или Object Storage. Домен остаётся тот же. Перенос делается после согласования, чтобы сайт не простаивал.

### Проверка сразу после заливки

Каждый адрес должен за один переход привести на `https://эвакуатор-34.рф/...` или вернуть 404:

```
curl -sI http://xn---34-5cdak1d7assj0j.xn--p1ai/          # 301 → https://…/
curl -sI https://www.xn---34-5cdak1d7assj0j.xn--p1ai/     # 301 → https://…/
curl -sI https://xn---34-5cdak1d7assj0j.xn--p1ai/index.php  # 301 → /
curl -sI https://xn---34-5cdak1d7assj0j.xn--p1ai/tseny     # 301 → /tseny/
curl -sI https://xn---34-5cdak1d7assj0j.xn--p1ai/nety-takoy/  # 404
```

Если `https://` сам на себя отвечает 301 (петля): закомментируйте блок «http → https» в `.htaccess` и включите HTTPS-редирект в панели хостинга. Затем:

```
python ~/.claude/skills/new-site-baseline/scripts/audit_site.py эвакуатор-34.рф --inner 5
```
